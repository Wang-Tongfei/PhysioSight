# Results

## synthetic_robustness (analysis logic only)

`synthetic_robustness.md` / `.json` are generated by
`python -m tools.experiments.synthetic_robustness --n 30` (seed 0, 90 random
scripts, 144 grid cells; the legacy engine is replayed on identical landmarks).
They measure the counting and fault logic on synthetic stick figures with
exact ground truth – **not** pose-model accuracy on real people.

What they show:

* **Aspect ratio (BC-1):** new engine 0.969 exact-count rate on both 16:9 and 1:1;
  legacy 0.647 on 16:9 vs 0.914 on 1:1.
* **Frame rate (BC-2):** new engine 1.000 at 30/60 fps and 0.948/0.930 at
  10/15 fps; legacy 0.833 at 30/60 fps and 0.733/0.722 at 10/15 fps. The
  remaining low-fps misses are fast repetitions whose bottom position falls
  between frames – a sampling limit, not a timer artefact.
* **Faults:** intended-fault recall 0.94–1.00 per exercise and 0 false alarms on
  clean repetitions.
* **Smoothing:** One Euro smoothing with default parameters *reduced* accuracy at
  every noise level (see DECISIONS D12), so it is opt-in.
* Legacy 30 fps < 1.0 although parity is exact at 30 fps on the fixture suite:
  the grid includes 16:9 frames, where the legacy engine fails (BC-1).
